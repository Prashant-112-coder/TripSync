# TripSync

**Intelligent Traveller Matching and Collaborative Trip Planning Platform**

TripSync is an MCA major-project web platform for discovering compatible travel companions, planning trips collaboratively, communicating with matched travellers, sharing expenses, improving traveller safety, and providing AI-assisted travel recommendations.

## Project Structure

```text
TripSync/
├── frontend/   # React + Vite + Tailwind frontend
├── backend/    # Node.js + Express REST API
└── docs/       # Architecture, requirements, and project documentation
```

## Scope Note

TripSync does **not** use RAG or a vector database. AI features are focused on matching, recommendations, and itinerary assistance.

## Development Approach

Development is carried out phase-wise. Each phase should be tested and committed to GitHub before moving to the next feature.
